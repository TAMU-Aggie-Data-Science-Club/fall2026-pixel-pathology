# Explain why overall accuracy alone can be misleading with uneven class sizes.

Neural networks, like CNN, are a form of supervised learning where it solves classification problems using labeled data. We therefore assign *accuracy* as the percentage of data that the CNN correctly classifies ([Goel 2026](https://www.geeksforgeeks.org/deep-learning/convolutional-neural-network-cnn-in-machine-learning/)). The existence of labeled data implies the possibility of  a *class imbalance*, or when labeled data is unequally distributed, or has an inherent bias between different classes. For example, given training data with thousands of images of dogs and a few with cats, the CNN will have a high accuracy but only perform well with dogs ([Kushwaha 2019](https://medium.com/x8-the-ai-community/solving-class-imbalance-problem-in-cnn-9c7a5231c478)). Accuracy is therefore not an accurate metric for CNNs as it does not provide the context for the data it was given and its internal performance.
